# Easybank Landing Page

This is a simple and responsive landing page for **Easybank**, created using **HTML** and **TailwindCSS**.

---

## Features

- **Header Navigation**:
  Links to sections like Home, About, Contact, Blog, and Careers.
- **Hero Section**:
  Highlights Easybank's features with a call-to-action button.
- **Why Choose Us Section**:
  Explains the benefits of using Easybank.
- **Blog Section**:
  Displays the latest articles.
- **Contact Section**:
  Provides email and phone contact information.
- **Footer**:
  Includes links to social media, support pages, and policies.

---

---

## Technologies Used

- **HTML5**
- **TailwindCSS**

---

## Sections

- **Home**: Introductory hero section with a call-to-action button.
- **About**: Explains why users should choose Easybank.
- **Blog**: Displays recent articles.
- **Contact**: Contact details for support or inquiries.
- **Careers**: Links to career opportunities.
